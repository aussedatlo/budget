# One task, one PR

- Every task gets its own branch from `main` and its own PR targeting `main`.
- Never add a new task's changes to an existing PR or branch, even a related one.
- Combine or stack work only when the user explicitly asks to, or links
  the tasks together.
- Follow-ups on the same task (review fixes, CI fixes) stay in its PR.
